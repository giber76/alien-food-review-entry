# One Star, Five Stars for the Food

Entry for [One Star, Five Stars for the Food](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7)
on make.fun — one sentence, at most 200 characters, in the voice of an
alien tourist giving planet Earth a one-star review while still slipping in
a real compliment about the food.

## The review (168 characters)

> One star: the oceans are undrinkable, the locals worship glowing rectangles, and gravity never once apologised — but the dumplings taste like the universe saying sorry.

## Why this sentence

- **Unmistakably a one-star alien review:** it opens with the verdict
  ("One star:") and every grievance is an outsider's bafflement at
  human habits — undrinkable oceans, locals worshipping glowing
  rectangles, gravity that never once apologised.
- **The food compliment is real, and it is the joke:** the dumplings
  taste like the universe saying sorry. The compliment lands because
  the complaints before it were deadpan, not angry — the food is the
  one thing on Earth the reviewer cannot fault.
- **Fresh angle:** no generic traffic / pollution / rude-humans list.
  The grievances are cosmic-scale observations only a visitor would
  make, and the food saves the planet by a hair.

## How it runs

`main.ts` (Node 22, standard library only) writes the sentence to
`/output/entry.txt`. Run locally with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
